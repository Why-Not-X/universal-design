Structure with semantic HTML

Use the element that matches the meaning, and assistive technology can understand your page for free.

  • Landmarks: header, nav, main, aside, and footer
  • One h1 and headings in order
  • Real lists, tables, and buttons

Navigation and keyboard

Everything you can do with a mouse should work with a keyboard.

  • Skip navigation links
  • Logical tab order, visible focus, and no keyboard traps
  • Marking the current page with aria-current

Images and media

Pictures and video need text alternatives.

  • Writing good alt text, and alt="" for decorative images
  • Captions and transcripts
  • Hiding decorative icons with aria-hidden

Color and contrast

Text has to stand out from its background, and color can't be the only way to show meaning.

  • WCAG contrast ratios: 4.5 to 1 for text, 3 to 1 for large text
  • Color blind safe palettes
  • Never using color alone

Typography and legibility

Readable type is accessible type.

  • Readable fonts and at least 16px body text
  • Line height around 1.5
  • Line length around 45 to 100 characters

Accessible forms

Forms are where many sites lock people out.

  • Labels tied to inputs
  • Grouping with fieldset and legend
  • Hints, required fields, and helpful error messages

Accessible data tables

Tables are for data, and screen readers need to know which header goes with each cell.

  • Captions
  • Header cells with scope
  • No tables for layout

ARIA and hidden content

ARIA can fill gaps, but native HTML comes first.

  • The first rule of ARIA
  • Hiding content visually with the .sr-only clip method vs. display: none

Responsive, mobile first layout

Start with the smallest screen and build up.

  • Mobile first CSS and media queries
  • CSS grid for layout and flexbox for navigation
  • Thumb-sized tap targets and zoom without sideways scrolling
  • Respecting reduced motion settings

Testing your work

Automated tools catch a lot, but you also need to try your site the way your users do.

  • The Nu HTML validator, WAVE, Silktide, Lighthouse, and the HTML5 Outliner
  • A keyboard-only test and a screen reader test
  • A launch checklist
